### 🤖 Trait: Internal AI Operations Portal

`Next.js 16` `React 19` `TypeScript` `NestJS 11` `Node.js` `TypeORM` `PostgreSQL` `Meta WhatsApp API` `Chatwoot` `Strapi` `Django` `Keycloak` `JWT` `RBAC` `Recharts` `TanStack Query` `Zustand` `Tailwind CSS v4` `BookStack` `REST APIs`

An internal AI operations platform that enables veterinary teams to monitor, manage, and optimize the AI agent handling customer conversations through WhatsApp. Built end-to-end across two repositories, covering backend services and frontend applications, with ongoing feature development and regular releases.

**Technical Highlights**

- Full-Stack Architecture: Built the backend using NestJS 11, TypeScript, TypeORM, and PostgreSQL, alongside a Next.js 16 and React 19 frontend.
- System Integrations: Integrated seven external systems, including Chatwoot, Meta WhatsApp Cloud API, Strapi, Django, BookStack, Pydantic Logfire, and Keycloak.
- Live Conversation Monitoring: Implemented real-time WhatsApp conversation monitoring with staff takeover capabilities, allowing human operators to intervene in AI-driven conversations.
- Analytics & Reporting: Developed dashboards for conversation volume, automation and escalation rates, AI costs, performance, booking funnels, revenue, and campaign metrics using Recharts, with date-range and per-clinic filters.
- Agent Prompt Management: Built prompt versioning workflows (draft, publish, activate), Git-style diffs, section reordering, and sandbox testing connected to the actual bot pipeline and pinned to specific prompt versions.
- LLM Optimization: Developed a prompt optimization workflow with checkpointed changes and accept/reject functionality.
- WhatsApp Campaign Management: Implemented campaign creation, template authoring, media management, recipient sheets, and campaign analytics.
- Knowledge Base Management: Integrated BookStack with live Markdown editing for managing the AI assistant's knowledge base.
- Authentication & Security: Implemented Keycloak JWT verification through realm JWKS using jose, role-based access control (RBAC), in-memory caching, AES-encrypted third-party credentials, rate limiting, Helmet, and service API key authentication.
- Frontend Architecture: Used TanStack Query, Zustand, and Tailwind CSS v4 to build a token-driven design system with light and dark modes.
- Internationalization: Implemented English and Arabic support with 1,806 translation keys and zero hardcoded UI strings.

**Impact**

- Operational Visibility: Provides veterinary teams with a centralized workspace to monitor AI conversations, supervise automation, and take over interactions when needed.
- Business Intelligence: Makes bookings, revenue, campaign performance, and AI operating costs accessible through unified analytics dashboards.
- AI Optimization: Enables teams to continuously refine agent prompts, test changes, manage knowledge, and improve automated conversations.
- Secure Integrations: Connects seven external systems through modular integrations with isolated authentication flows and protected credentials.
- Data Integrity: Enforces a strict no-fabrication principle. Every metric traces back to an actual upstream data field. Missing values return null from the API and appear as explicit empty states in the UI rather than estimated or fabricated numbers.
